# Merge Defense Privacy Policy

Static, mobile-friendly privacy policy page for Merge Defense.

## Publish with GitHub Pages

1. Open **Settings** for this repository.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to finish publishing.

Expected public policy URL:

https://zulkifill.github.io/Merge-Defense-Privacy-Policy/

Use that URL in the Privacy Policy field in Google Play Console after confirming it opens publicly without signing in.

## Policy maintenance

Keep the policy accurate whenever the app's SDKs, purchase handling, analytics, advertising, or data collection changes. The current policy reflects the implementation details supplied for this release; verify these statements against the final production build before submitting.
